# Sixty% 1.3 — What's New (English)

Paste into App Store Connect → version 1.3 → "What's New in This Version".

```
• Smarter reminders: no reminder when the day is already logged, or is a public holiday, leave or a sick day. Changing the reminder time now takes effect straight away.
• See how many office days you have left including your planned days, on both the calendar and the overview.
• The "This year" chart now shows planned days in green, with the percentage in brackets.
• Clearer labels and a slightly tidier overview page.
```
